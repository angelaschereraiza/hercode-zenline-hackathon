# Retail Radar Frontend

Clean React/Vite demo frontend for the HerCode × Zenline Retail Radar project.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## What is included

- Clean executive dashboard
- Retailer context switcher
- Act Now / Watch split
- Opportunity detail view
- Score breakdown
- Risk register
- Monitor triggers
- Evidence table
- Download links for `recommendations.json` and `signals.csv`

The frontend reads static data from:

- `public/recommendations.json`
- `public/signals.csv`
